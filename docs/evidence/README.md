# Experiment Evidence

This directory contains immutable, machine-readable summaries cited by a
current paper or maintained technical contract.

- [`adaptive/`](adaptive/) contains topology, recurrent-training, LoD, and
  continuous-scale adaptive NPA reports.

Raw checkpoints, per-step logs, benchmark matrices, caches, and generated
render directories belong under ignored experiment output paths. A report
should be removed when no maintained document or verified configuration uses
it.
